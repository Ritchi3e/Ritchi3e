## Olá, eu sou o Gustavo 👋

Estudante de **Engenharia de Software** na Faculdade Uniguaçu e **analista de QA** no JACAD (SWA Sistemas), um sistema de gestão acadêmica usado por instituições de ensino.

No trabalho, testo funcionalidades de ponta a ponta: escrevo casos de teste a partir dos requisitos, investigo erros nos logs do servidor (Kubernetes) e documento tudo para os desenvolvedores e para os clientes. Nos projetos, levo essa mesma visão de qualidade para o desenvolvimento full-stack.

### 🚀 Projeto em destaque

**[App Geek](https://github.com/Ritchi3e/App-Geek)**: sistema web de inscrições por QR Code e caixa (PDV) das barracas para eventos acadêmicos, com controle de acesso por grupos de usuários.
Feito com Next.js, React, TypeScript e PostgreSQL. Tem 421 testes automáticos e 28 casos de teste ligados aos requisitos. Foi apresentado no VI Encontro de Pesquisa, Extensão e Inovação da Uniguaçu.
